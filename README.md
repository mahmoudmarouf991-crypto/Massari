# مساري — Flutter

متابعة العبادات اليومية (الصلاة، القرآن، الدراسة الدينية، الصيام، عمل الخير، الرياضة)
+ مواقيت صلاة محسوبة فلكيًا + تاريخ هجري + تقرير أسبوعي + تقويم شهري
+ **تذكير الأدوية والفيتامينات والكرياتين** (إشعارات حقيقية حتى والتطبيق مقفول).

## أسهل طريقة: APK جاهز من GitHub (من غير ما تثبّت أي حاجة)
1. اعمل حساب على github.com وأنشئ Repository جديد (Private عادي).
2. ارفع كل ملفات المشروع (بما فيها المجلد المخفي `.github`).
   لو `.github` ماترفعش: "Add file ▸ Create new file" واكتب الاسم
   `.github/workflows/build-apk.yml` والصق محتوى الملف الموجود جوه المشروع.
3. ادخل تبويب **Actions** ▸ **Build APK** ▸ **Run workflow**.
4. بعد حوالي 5–8 دقايق افتح التشغيل الناجح، نزّل **masari-apk** من آخر الصفحة (Artifacts)،
   فُكّه وثبّت `app-release.apk` على موبايلك (فعّل "التثبيت من مصادر غير معروفة" أول مرة).

لو التشغيل فشل، افتح الخطوة الحمرا وابعتلي نص الخطأ.

## التشغيل على جهازك (لو عندك Flutter)
```
flutter create .
python tools/patch_android.py
flutter pub get
flutter run
```
أو لبناء APK: `flutter build apk --release` (الناتج: `build/app/outputs/flutter-apk/app-release.apk`).

## تبويب "الأدوية"
- أضف أي دواء/فيتامين/كرياتين باسمه وموعده وجرعته (اختياري) وأيامه.
- إشعار في الميعاد حتى لو التطبيق مقفول، ويتجدول تاني بعد إعادة تشغيل الموبايل.
- قايمة "جرعات اليوم" تعلّم عليها لما تاخدها، وزرار إشعار تجريبي.
- أول مرة هيطلب إذن الإشعارات وإذن "المنبهات الدقيقة" (لو رفضته التذكير هيشتغل لكن ممكن يتأخر دقايق).
- على أجهزة شاومي/أوبو/هواوي: فعّل "التشغيل التلقائي" وأوقف "توفير البطارية" للتطبيق.
- التطبيق بيفكّرك بالمواعيد اللي أنت حددتها بس، ومش بيدّي نصايح علاجية.
